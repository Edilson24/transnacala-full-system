Para ejecutar tu aplicación FastAPI:
python -m uvicorn main:app --reload --port 8000

Para exponer tu aplicación FastAPI a través de un túnel seguro usando Cloudflare, puedes usar los siguientes comandos:
cloudflared tunnel --url http://localhost:8000
cloudflared tunnel --protocol http2 --url http://localhost:8000

Para criar un subdominio específico para tu aplicación, puedes usar el siguiente comando:
lt --port 8000 --subdomain lory-lifter-api
lt --port 8000 --subdomain lory-lifter-api --local-host 127.0.0.1
